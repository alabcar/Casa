# Calculadora casa Foios

Calculadora orientativa (HTML/JS, sin dependencias) para ver hipoteca final, cuota y colchón al comprar la casa y vender el piso.

- `index.html`: página lista para abrir (generada).
- `model.js`: modelo de cálculo.
- `template.html` + `build.py`: plantilla y script que incrusta el modelo (`python3 build.py`).
- `test.js`: comprobaciones del modelo (`node test.js`).

Los valores por defecto son personales: mantener el repo privado.
